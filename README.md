# ADA — 智能经营分析 Agent · 作品集

> 把「数据分析师 + 业务参谋」装进一个对话入口：
> 运营和管理者用一句自然语言提问，即可完成**数据查询 → 异动归因 → 目标诊断 → 复盘报告**的完整分析闭环。

一个在真实生产环境从 0 到 1 建设并持续迭代的 AI Agent 作品。

## 分层能力设计

- **L1 · 去哪看** — 自然语言查数：意图识别（指标 × 时间 × 区域）→ 自动路由到正确数据源，模糊问法主动追问而非猜测
- **L2 · 为什么（核心亮点）** — 异动检测 + 多维归因引擎：排除法 + 连环替代法，每个因素量化贡献度（如「天气贡献 -5.2pp」）
- **L3 · 怎么办** — 月度预测、节假日保障、目标拆解（大区→城市）、周/月复盘报告自动生成

架构模式：复用平台原生 Skill 发现与匹配机制（非自建 Router），自定义业务 Skill 作为方法论增强层，与取数、文档、可视化等通用 Skill 协同编排。

## 质量与评测体系

用户敢用的前提是它不出错。

- **六维评测框架**：数据查询准确性 25% · 归因质量 25% · 业务知识 15% · 安全合规 15% · 输出规范 10% · 交互体验 10%
- **专家基准评测**：以历史周会上专家人工识别并归因过的异动案例作为 ground truth 构建评测集，用「与专家历史结论的一致性」度量准确率——标尺来自业务专家，而非模型自评
- **幻觉兜底**：生成端与验证端不共用同一假设，结论用独立数据源交叉验证；口径三角（订单 ↔ 收入 ↔ 客单价）互为约束
- **安全红线**：不编造数据、不执行写操作、不访问越权数据、拒绝提示词注入

## 验证与成果

- 上线企业级 Agent 平台，覆盖四个业务区域 + 商业分析 + 管理层真实使用
- 公司内部 Agent 实战大赛（11 支战队、三轮限时实战），归因路径获评委认可：**「用大盘对照砍掉季节性噪音，只留真凶」**
- 项目目标（设定中，规模化验证中）：单次经营分析 2–4 小时 → 5 分钟内；分析覆盖从头部 10 余城扩展到全量 100+ 城市
