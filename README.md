## 02 · 界面 Demo

**真实产品形态：前端机器人，后端编排**——前端即 IM 机器人（群聊 / 私聊 / 定时任务三类入口），后端由企业 Agent 平台统一编排：接收消息 → 意图识别与数据源路由 → 调用接入的业务看板 / 数据平台接口完成取数、目标上传 → 结构化回复，全程统一鉴权与留痕。角色定位：**数字员工**。

页面内嵌示意对话（基于真实归因流程）：用户问「成都昨天订单环比降了 8%，什么原因？」→ ADA 结论先行（主因降雨 -5.2pp、次因供给 -1.8pp）→ 归因量化表 → 数据来源标注 → 追问给出预测与行动建议。

## 03 · AI 实践成果（三条端到端链路）

协作模式：人定义问题和验收标准 → Skill 执行单步确定性任务 → Agent 编排多 Skill 完成端到端链路 → 最终结论由人审核确认。

1. **预测全流程**：天气取数 → LightGBM 预测分天订单收入 → 按节假日节奏拆解到天 → 自动上传目标平台，一句话触发。MAPE<5%，取数到上传 2–3 天手工流程 → 分钟级
2. **月报全流程**：自动创建月报文档串联撰写→检查→审核→发布；批量查询达成值/MoM/YoY 回填模板；归因下钻 Top5 城市。月会「一张表」定时任务自动回填
3. **人机协同**：预警提报自动收集与 DDL 提醒；自然语言数据问答；实际时序数据交叉验证自报影响合理性；群内自动验收作业

页面含两张真实截图：群聊 @ADA 提交作业自动验收（人名已脱敏）、月会「一张表」数据模板（部分数据已脱敏）。Skill 资产：13 个业务 Skill 发布至企业技能广场，累计下载 493 次、调用 509 次。

## 04 · 实现逻辑

**三层能力架构**：L1 数据查询（意图识别 → 自动路由数据源）→ L2 归因诊断 ★（异动检测 + 排除法 + 连环替代法）→ L3 策略建议 + 效果复盘（供需匹配、价格策略、天气/节假日保障方案；策略落地后基于实验组/对照组数据自动复盘增量效果，形成「归因 → 策略 → 验证」闭环；同时承载预测 / 目标拆解 / 复盘报告）。复用平台原生 Skill 发现与匹配（非自建 Router），自定义业务 Skill 沉淀方法论。

**知识库与指标图谱**（归因能力的地基，四步）：

1. **指标因果图谱** — 指标为节点、4 种关系为边（分解/影响/抑制/传导），内嵌 5 条归因推理规则（天气优先、供给先于需求、相关性≠因果…）
2. **协同建设机制** — 零代码应用唯一数据源（4 张表），9 模块 Owner 分权；AI 零写入，人类逐条确认 + 版本回滚
3. **策略知识库** — 30+ 策略原子六类，按「收敛→分层→基准→判定→分解→下钻→收口」串成流水线
4. **运营与自迭代** — 弃纯 RAG，增量编译 Wiki（Ingest/Query/Lint）复利增长；「记忆 → Skill」自迭代闭环

查询引擎为嵌入式图数据库，查询前自动版本同步（约 200 节点 / 500 边，重建 <2s）。

## 05 · 对标业界头部 Agent 产品

| 业界标杆 | 业界做到了什么 | ADA 的对位与差异 |
|---|---|---|
| Databricks Genie / Snowflake Cortex Analyst | 对话式数析标杆：自然语言自助取数、语义层护住口径 | ADA 同样实现一句话取数，并用因果图谱硬编码口径，工具成功率 99.5%、数值必标来源 |
| Tableau Pulse / 瓴羊智能归因 | 波动提醒 + 维度下钻式归因 | 排除法 + 连环替代法因果量化到 pp 级，专家 ground truth 评测一致率 92%，把「描述波动」升级为「定位原因」 |
| Manus / Devin 等通用 Agent | Agent 自主完成端到端任务 | 同一范式在垂直经营场景的生产级落地：预测全流程一句话触发、2–3 天手工流程 → 分钟级 |
| Letta（MemGPT）/ LangGraph Memory | Agent 记忆分层与长期记忆 | 「记忆 → Skill」自迭代闭环，好经验蒸馏验证后版本化发布为技能，13 个业务 Skill 已发布 |
| AutoGen / CrewAI 多智能体框架 | 多 Agent 协作编排 | Skill 干确定性活 + Agent 编排 + 人审核结论，避开多 Agent 互传幻觉 |
| RAG 类知识问答（主流 ChatBI 做法） | 向量检索拼凑上下文 | 弃纯 RAG：原始资料 → Wiki → Schema 三层编译，可版本化、复利增长 |

业界头部产品验证了方向，但多数停在通用能力层；ADA 把「确定性引擎 + 可治理知识 + 可验证评测」在真实生产环境跑通，并拿出 92% 归因一致率、99.5% 工具成功率、100% 对话成功率的可验证数据。

**正在引入的业界设计（Roadmap）**：① 借鉴 Cortex Analyst 语义层——因果图谱升级为可复用语义层；② 借鉴 Tableau Pulse——从问答升级为主动洞察推送 + 个人订阅（定时巡检已上线）；③ 借鉴 Manus / Devin——复杂归因任务「计划-执行-验证」循环，步骤可观测可干预；④ 借鉴 Code Interpreter——归因计算沙箱化，可复现可审计；⑤ 借鉴 AutoGen / CrewAI——多智能体分工编排已规划。
