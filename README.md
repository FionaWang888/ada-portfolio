## 01 · 功能介绍

| 能力 | 要点 |
|---|---|
| 统一指标查询 | 单/多指标、跨对象对比、目标达成查询；数值标注来源，可回溯验证 |
| 异动归因引擎 ★ | 「先外后内、先大后小」：天气/节假日优先排除 → 供给 → 需求；量化到 pp 级贡献 |
| 目标管理 | 实际值与目标值分源获取、MTD 达成率、Gap 定位；目标拆解到城市 |
| 报告自动化 | 周/月复盘自动生成并发布；每日定时巡检城市指标异常 |
| 分层交互 | 群聊结论先行、限长、密级管控；私聊完整报告 + 多轮追问 |
| 统一鉴权与权限管控 | 下游调用统一 SSO 换票校验，按对话人身份隔离、最小授权、留痕可审计 |

## 03 · 实现逻辑

**三层能力架构**：L1 数据查询（意图识别 → 自动路由数据源）→ L2 归因诊断 ★（异动检测 + 排除法 + 连环替代法）→ L3 决策支持（预测 / 目标拆解 / 复盘报告）。复用平台原生 Skill 发现与匹配（非自建 Router），自定义业务 Skill 沉淀方法论。

**知识库与指标图谱**（归因能力的地基，四步）：

1. **指标因果图谱** — 指标为节点、4 种关系为边（分解/影响/抑制/传导），内嵌 5 条归因推理规则（天气优先、供给先于需求、相关性≠因果…）
2. **协同建设机制** — 零代码应用唯一数据源（4 张表），9 模块 Owner 分权；AI 零写入，人类逐条确认 + 版本回滚
3. **策略知识库** — 30+ 策略原子六类，按「收敛→分层→基准→判定→分解→下钻→收口」串成流水线
4. **运营与自迭代** — 弃纯 RAG，增量编译 Wiki（Ingest/Query/Lint）复利增长；「记忆 → Skill」自迭代闭环

查询引擎为嵌入式图数据库，查询前自动版本同步（约 200 节点 / 500 边，重建 <2s）。
